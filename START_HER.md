# START HER — Cirkel

Hele Cirkel-systemet i én mappe, klar til Claude Code.

1. Pak ud, åbn mappen i Claude Code.
2. Bed Claude læse **CLAUDE.md** (indgang + systemkort + regler).
3. Kør appen: `npm install` → `npm run dev` → http://localhost:3000.

Vil du se holdet: åbn **cirkel_team_console.html** i en browser.
Reglerne: **AI_TEAM_GOVERNANCE.md**. Deployment: **DEPLOY.md**.

Vigtigst: intet ændres uden din accept — hvert forslag vises først.
